# Mobile response polish, versions 11 and 12

Checkpoint: September 7, 2026. Version 12 is active.

## Changes

- Routine answers target 35 to 60 words including source notes. This is a prompt target, not deterministic enforcement.
- Removed conflicting instructions that invited optional closing offers. Ask questions only when required information is missing or support consent is needed.
- Full service-generated support drafts, consent and safety disclosures are exempt from brevity targets.
- Native file citations remain disabled. Original public links and source provenance remain required.
- Version 11 replaced the classification summary in the Data Library. The replacement was observed Indexed with ten total files. Historical numerical age thresholds, lead times and required classification-category claims were removed; the prior file is recoverable in Git history.
- No permissions, OAuth settings, Apex actions or support confirmation logic changed. The external MCP application remains disabled.
