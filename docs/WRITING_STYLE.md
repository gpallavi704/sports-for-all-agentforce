# Project writing style

Use plain language and short sentences. Do not use em dash punctuation in project-authored responses, scripts, prompts, documentation or GitHub content. Prefer periods, commas, colons, parentheses or ordinary hyphens as appropriate.

Preserve original source quotations and historical test evidence rather than rewriting what a source or agent actually said. JSON evidence may encode punctuation with Unicode escapes without changing the recorded string. Third-party dependencies are not project-authored content.

The active version 12 Sport Compass prompt includes this rule. Routine replies target 35 to 60 words including source notes, with no automatic closing offers. Ask follow-up questions only to resolve required missing information or obtain support consent. Safety details and the complete service-generated support disclosure must not be truncated to meet a word target. These are prompt instructions, not guaranteed output-length enforcement. Existing generated versions are historical snapshots, not the current editable prompt.
